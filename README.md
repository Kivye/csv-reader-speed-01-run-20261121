A faster drop-in for make.fun's csv-reader 1.0.0 — reads broken CSV files with byte-identical answers ({columns, rows, errors}) at a fraction of the CPU time. Clean lines take a bulk split fast path; quoted fields are sliced with native indexOf scans instead of per-character string building.

## Run it

```sh
node main.ts
```
